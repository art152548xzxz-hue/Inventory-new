# 📦 Inventory Management System (Greekzly)

ระบบบริหารจัดการสต็อกสินค้าและวัตถุดิบ (Inventory Management System) สำหรับติดตาม ควบคุม และสรุปรายงานยอดคงเหลือวัตถุดิบ สินค้า พร้อมระบบแจ้งเตือนเมื่อสินค้าใกล้หมด

---

## ✨ คุณสมบัติหลัก (Key Features)

* 📊 **Dashboard ภาพรวม:** แสดงยอดสรุปสต็อก สินค้าขายดี และสถานะการเบิก-จ่าย
* 📦 **จัดการวัตถุดิบ & สินค้า (Stock Management):** เพิ่ม ลด แก้ไข และลบรายการสินค้าในระบบ
* ⚠️ **ระบบแจ้งเตือนสต็อกต่ำ (Low Stock Alert):** เตือนทันทีเมื่อวัตถุดิบหรือสินค้าลดลงแตะระดับขั้นต่ำ
* 🔄 **ประวัติการทำรายการ (Transaction Logs):** บันทึกประวัติการรับเข้า-จ่ายออกเพื่อความแม่นยำ
* 📱 **รองรับ Responsive Design:** ใช้งานได้สะดวกทั้งบนคอมพิวเตอร์ แท็บเล็ต และมือถือ

---

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)

* **Frontend:** [React.js](https://reactjs.org/) + [Vite](https://vitejs.dev/)
* **Styling:** [Tailwind CSS](https://tailwindcss.com/)
* **Icons:** [Lucide React](https://lucide.dev/)
